# Codex Toolbox Guidelines

- This repository is the public release aggregate and a generated consumer of
  `Joey-Tools/codex-personal-sync`; it is not the semantic source of the sync
  engine, manifest schema, or their mirrored tests.
- Treat `generated-sync-source-lock.json` and every target it lists as
  generated read-only files. Make semantic changes in `codex-personal-sync`,
  then regenerate from its exact committed source SHA with the canonical
  generator.
- Consumer-owned packaging, release workflows, public skills, manifests, and
  helper binaries remain editable here. Never copy consumer changes back into
  canonical generated sources.
- Require generated bytes, modes, mapping, file-set digest, tree digest, and
  canonical commit identity to match the provenance receipt before delivery.
- Keep ordinary workstream state in `docs/project_journal/YYYY/MM/*.md`; the
  top-level project trackers, when present, are only short repo-wide entrypoints.
